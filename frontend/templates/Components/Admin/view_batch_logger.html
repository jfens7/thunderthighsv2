Speed-Logger & Batch Queue

Retroactively log set points sequentially. Uses smart shorthand to speed up data entry.

How to use Shorthand Input

Instead of typing full scores (11-9, 3-11, 11-4), just type the loser's score separated by spaces. The system already knows who won the overall match.

• Positive Number (e.g. 9): The match winner won this set. (Auto-converts to 11-9)
• Negative Number (e.g. -3): The match loser won this set. (Auto-converts to 3-11)

Example for 3-1 Win
9 9 -3 4
11-9, 11-9, 3-11, 11-4
